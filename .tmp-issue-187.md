## Context

## Acceptance criteria
- [ ] A scheduled or triggerable job can refresh configured sources into the vector store.
- [ ] Idempotent behaviour for unchanged content (no duplicate chunk storms).
- [ ] Failures are logged with request/correlation style observability (#160 patterns).
- [ ] Operator docs cover enablement and safe rollback (e.g. wipe chroma note where relevant).
- [ ] Tests cover sync success and partial failure.

## Out of scope
