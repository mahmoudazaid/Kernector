TITLE: Add user authentication and personalisation

## Context
125.md Medium optional: user authentication and personalisation.

The Streamlit app is currently single-tenant / anonymous session state.

## Acceptance criteria
- [ ] Users can sign in with a documented auth approach (local/dev-friendly is OK for Sprint 2).
- [ ] Unauthenticated users cannot access personalised state.
- [ ] At least one personalisation surface exists (e.g. preferred provider/model or saved preferences) scoped to the user.
- [ ] No secrets written into chat history or logs.
- [ ] Architecture stays presentation-agnostic where practical (contracts not Streamlit-only).

## Out of scope
Full multi-tenant org RBAC. Next.js-only auth UI.
