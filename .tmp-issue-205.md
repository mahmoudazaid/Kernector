TITLE: Configure hybrid search (enable + alpha) from the Streamlit UI

## Context

Product hybrid search (BM25 + vector) landed in #185 and is enabled only via env (`HYBRID_SEARCH_ENABLED`, `HYBRID_ALPHA`). Operators/devs should be able to toggle and tune hybrid retrieval from the Streamlit UI without editing `.env` and restarting.

## Story

As a Kernector user, I want to enable hybrid search and set its BM25 weight from the UI so I can try lexical+vector retrieval without redeploying config.

## Acceptance criteria

- [ ] Sidebar (or equivalent settings surface) exposes:
  - hybrid search on/off
  - BM25 weight (`alpha` in `[0, 1]`, documented as BM25 weight)
- [ ] UI values drive the retrieve path for the current session (or process) without requiring a process restart for enable/disable and alpha changes
- [ ] Default remains vector-only when the user has not opted in (aligned with `HYBRID_SEARCH_ENABLED=false`)
- [ ] Changing settings does not break metadata-filter semantics or relevance-threshold behaviour for vector-only mode
- [ ] Shared DualWrite / cached vector store stays consistent when hybrid is toggled on (hydrate or dual-write as needed) and when toggled off (vector-only path)
- [ ] Docs note that UI settings override or supplement the env defaults for local runs
- [ ] Tests cover UI→composition wiring for on/off and alpha extremes
