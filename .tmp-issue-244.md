TITLE: Apply Kernector logo and app icons for Instrument panel identity

## Epic

#73 Replaceable UI and Branding

## User story

As a user, I want Kernector’s real logo and app icons in the Next.js shell and browser chrome so the Instrument panel identity (ADR 0003) reads as one product, not a placeholder letter mark and default favicon.

## Context

Today:

- Shell brand mark is a text **K** in `.kern-brand-mark` (`web/components/shell/AppShell.tsx`).
- Browser tab uses stock `web/app/favicon.ico` (Next.js default).
- No first-party `icon` / `apple-icon` / OG image set aligned with Instrument panel tokens (slate neutrals, restrained teal).

ADR 0003 already names the brand mark as part of shell chrome; this ticket ships the actual mark and icon suite.

## Exact scope

- Add a product logo (SVG preferred) that fits Instrument panel: cool slate + restrained teal; works on light and dark shell surfaces.
- Replace the shell **K** mark with the logo (keep wordmark “Kernector”; remain domain-neutral — no pack branding).
- Ship browser / PWA-style icons: favicon, `icon` sizes, and `apple-icon` (and optional OG/social image if cheap).
- Wire Next.js App Router metadata (`app/icon.*`, `app/apple-icon.*`, and/or `metadata.icons`) so tabs and home-screen bookmarks show Kernector, not the Next default.
- Document where logo/icon sources live (e.g. `web/public/` or `web/app/`) in `web/README.md` Visual direction.
- Keep contrast and sizing readable at small header / favicon scales.

## Exclusions

- Redesigning the full Instrument panel token system (already ADR 0003 / `tokens.css`)
- Pack- or connector-specific logos
- Marketing landing / broadsheet branding looks called out as non-goals in ADR 0003
- Streamlit presentation branding

## Acceptance criteria

- [ ] Shell brand uses the Kernector logo asset instead of the letter **K**.
- [ ] Favicon / app icons are first-party Kernector assets (no Next.js default).
- [ ] Logo and icons remain legible in light and dark themes.
- [ ] Metadata exposes the icon set so browser tabs and common “Add to Home Screen” paths show Kernector.
- [ ] `web/README.md` notes where logo/icon assets live and how to replace them.
- [ ] Shell navigation tests still assert brand presence; update assertions if markup changes.

## Dependencies

- Parent epic **#73**
- Complements **#99** (tokens/flags) and closed shell foundation **#126**
- Visual system: **ADR 0003** Instrument panel

## Definition of Done

- [ ] Logo in shell + icon suite shipped
- [ ] Default Next favicon removed or superseded
- [ ] Docs/tests updated for the new brand assets
