TITLE: Epic: Replaceable UI and Branding (Sprint 2)

## Goal

Streamlit is a presentation adapter only; branding lives in UI-agnostic tokens/config; Next.js remains a future adapter.

Feature flags may enable providers, connectors, and optional domain packs, while shared branding, configuration contracts, and runtime behavior remain **domain-neutral**. Disabling packs/connectors must not break core startup, upload, retrieval, or generic chat.

## Definition of Done

- No business logic or session_state in domain/application.
- Branding tokens cover colors, typography, logos, spacing, terminology, feature flags.
- Flags can gate packs/connectors without moving pack semantics into default branding.
