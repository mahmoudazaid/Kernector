TITLE: Restore test-case / conversation export (JSON, CSV, PDF) in Next.js

## Epic

#124 Next.js presentation foundation and incremental Streamlit migration

## User story

As a user, I want to download grounded chat / test-case transcripts as JSON, CSV, or PDF from the Next.js app so Streamlit retirement (#228) does not remove a shipped export capability.

## Context

Streamlit `render_test_cases_export_actions` offers three downloads that Next.js chat does not:

| Download | Producer | Next.js today |
| --- | --- | --- |
| JSON | `presentation/streamlit/cases_export.cases_to_json` | none |
| CSV | `presentation/streamlit/cases_export.cases_to_csv` | none |
| PDF | `cases_pdf_turns` → `composition.conversation_export.build_conversation_pdf` → `infrastructure/export/conversation_transcript_pdf` | none |

`web/components/chat/ChatPanel.tsx` only offers **Copy markdown**. #235 covered chat ask parity, not export. Closed Streamlit work: #181.

#228 Decision 1 recommends keeping `composition/conversation_export.py`, `infrastructure/export/`, and `fpdf2` dormant (delete only Streamlit `cases_export`) and naming this ticket as the known regression in ADR 0004.

## Exact scope

- Expose export of the current conversation (or selected turns / test cases) as JSON, CSV, and PDF from Next.js — client-side generation and/or `/api/v1` endpoints, reusing the dormant PDF stack where practical.
- Keep Markdown / copy-markdown available.
- Sanitize exports: no secrets, raw tool payloads, or leaked prompts.
- Cover each format at the presentation / HTTP boundary with offline tests.
- Update migration-readiness / ADR notes once the gap is closed.

## Exclusions

- Streamlit retirement itself (#228)
- Auth-gated personal export history
- Rewriting domain/application ask logic

## Acceptance criteria

- [ ] User can export the current conversation (or selected assistant turn / test cases) as JSON from Next.js.
- [ ] User can export as CSV (sensible columnar projection of role/content/timestamp where available).
- [ ] User can export as PDF (readable transcript; no secrets/tool payloads), preferably via the existing `build_conversation_pdf` path.
- [ ] Markdown / copy-markdown remains available.
- [ ] Tests cover each export path at the presentation boundary without live model calls.
- [ ] Architecture boundaries stay intact (Next talks over HTTP; export builders stay in composition/infrastructure as today).

## Dependencies

- Parent epic **#124**
- Follow-up to Streamlit retirement **#228** (Decision 1 / ADR 0004 known regression)
- Related closed Streamlit export: **#181**
- Not covered by chat parity **#235**

## Definition of Done

- [ ] JSON, CSV, and PDF export usable from Next.js chat / test-case UI
- [ ] Dormant export stack either wired or deliberately replaced with equivalent coverage
- [ ] Tests + architecture gates green; migration-readiness / ADR gap closed
