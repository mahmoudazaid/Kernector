TITLE: Enhance Next.js Chat screen UX

## Epic

#124 Next.js presentation foundation and incremental Streamlit migration

## User story

As a user, I want the Next.js Chat screen to feel clearer and easier to use so everyday ask turns are less friction without changing the underlying ask API.

## Context

Grounded chat parity (#235) shipped ask turns, citations, tools, run details, and a single local transcript (`kernector:chat-messages:v1`). This ticket is **presentation polish only** — not multi-conversation history (separate ticket) and not export (#243).

## Exact scope

- Improve Chat layout and hierarchy under Instrument panel (ADR 0003): empty state, thread readability, composer focus, sticky/send affordances, spacing density.
- Clarify **New chat** vs continuing the current transcript (copy and placement), without introducing a conversation list.
- Tighten loading / error / unavailable states for scanability; keep sanitized Problem Details messaging.
- Small a11y and keyboard wins on composer and primary actions (focus order, labels, live region behavior if needed).
- Keep shell domain-neutral; no pack-specific chrome.

## Exclusions

- Multi-conversation list / resume past chats (follow-up history ticket)
- JSON/CSV/PDF export (#243)
- LangGraph agent memory (#213)
- Auth (#182), generation-settings expansions (#220)
- Ask HTTP contract changes beyond what polish requires

## Acceptance criteria

- [ ] Empty, in-progress, success, and failure states are clearer and consistent with Instrument panel chrome.
- [ ] Composer and New-chat controls are easier to find and use on desktop and mobile widths.
- [ ] Keyboard / screen-reader basics for send and New chat remain correct (or improve).
- [ ] No change to multi-thread persistence model in this ticket (still one local transcript).
- [ ] Existing chat panel / turn tests updated or extended for any markup/copy changes; suite stays green.

## Dependencies

- Parent epic **#124**
- Builds on closed chat parity **#235**
- Visual system: ADR 0003
- Distinct from chat history / resume follow-up and **#243**

## Definition of Done

- [ ] Chat UX polish merged on Next.js `/chat`
- [ ] Tests/docs notes updated if user-visible behavior or copy changed
- [ ] Lint/typecheck/chat tests green
