TITLE: Add human-in-the-loop interrupts for tool approval

## Context

Sprint 3 topics include human-in-the-loop. High-impact tools (exports, external writes) should pause for approve/reject before executing.

## Goal

Add LangGraph interrupts (or equivalent HITL) for at least one high-impact Software Delivery tool path, with UI to approve or reject.

## Acceptance criteria

- [ ] Agent pauses before a designated risky tool until the user approves or rejects
- [ ] Streamlit (or HTTP/Next) surfaces pending interrupt state clearly
- [ ] Reject cancels the tool without side effects; approve continues the graph
- [ ] Failures map to existing error taxonomy
- [ ] Tests cover approve and reject paths with fakes
