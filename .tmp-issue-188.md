TITLE: Multi-language support for UI and answers

## Context
125.md Hard optional: add multi-language support.

## Acceptance criteria
- [ ] UI chrome (labels/help) can switch between at least two languages.
- [ ] Ask path accepts non-English queries without breaking retrieval (documented behaviour).
- [ ] Responses can follow a selected response language preference when configured.
- [ ] No secrets/PII logged from localisation layers.
- [ ] Tests cover language preference plumbing at the boundary used by Streamlit.

## Out of scope
Full i18n of every pack prompt. Automatic translation of the entire knowledge corpus.
